# پورتفولیوی مجید فکرمند

پورتفولیوی شخصی مجید فکرمند (Full Stack Developer) — ساخته‌شده با Next.js 14 (App Router)، TypeScript، Tailwind CSS و Framer Motion، با خروجی کاملاً استاتیک برای هاست‌های رایگان.

## ⚠️ نکته مهم درباره این نسخه

این پروژه به‌صورت **کد سورس کامل و ساخته‌نشده (unbuilt)** تحویل داده شده است. چون محیطی که این فایل‌ها را تولید کرده به اینترنت دسترسی نداشت، امکان اجرای `npm install` و `next build` وجود نداشت — یعنی:

- کد **تست اجرا نشده** و ممکن است نیاز به رفع چند خطای کوچک (type error، import ناقص و...) داشته باشد.
- تصاویر پروژه‌ها (`/public/assets/projects/*.jpg`) و کاور مقالات وبلاگ صرفاً به‌عنوان مسیر در نظر گرفته شده‌اند و باید خودتان تصاویر واقعی را جایگزین کنید.
- آدرس فرم تماس (`FORMSPREE_ENDPOINT` در `src/components/sections/ContactForm.tsx`) باید با ID واقعی فرم Formspree خودتان جایگزین شود.
- دامنه سایت در `src/lib/seo.ts` و `next-sitemap.config.js` به‌صورت `https://majidfekrmand.ir` تنظیم شده — آن را با دامنه واقعی خود عوض کنید.

## نصب و اجرا (روی سیستم خودتان)

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

## ساخت نسخه نهایی (Static Export)

```bash
npm run build
```

این دستور:
1. پروژه را build می‌کند.
2. خروجی استاتیک را در پوشه `/out` قرار می‌دهد (به‌خاطر `output: "export"` در `next.config.js`).
3. اسکریپت `postbuild` به‌صورت خودکار `sitemap.xml` و `robots.txt` را داخل `/out` می‌سازد.

## استقرار روی InfinityFree

1. پس از اجرای `npm run build`، محتوای کامل پوشه `/out` را کپی کنید.
2. وارد پنل InfinityFree شوید و از File Manager یا FTP استفاده کنید.
3. تمام فایل‌های داخل `/out` را داخل پوشه `htdocs` آپلود کنید.
4. اطمینان حاصل کنید فایل `index.html` مستقیماً داخل `htdocs` قرار دارد (نه داخل زیرپوشه).

همین مراحل برای GitHub Pages، Netlify (Static) و Cloudflare Pages هم با تنظیمات ساده مشابه قابل انجام است — کافی است پوشه خروجی build را `out` معرفی کنید.

## ساختار پروژه

```
src/
  app/            مسیرهای صفحات (App Router)
  components/
    ui/           کامپوننت‌های پایه (دکمه، کارت شیشه‌ای، کانتینر)
    sections/     بخش‌های اصلی صفحات (هیرو، درباره من، خدمات، ...)
    animations/   کامپوننت‌های انیمیشن (FadeUp، RevealText)
    layout/       ناوبری، فوتر، JSON-LD
  data/           فایل‌های JSON محتوای پروژه‌ها، خدمات، قیمت‌گذاری، مهارت‌ها
  lib/            توابع کمکی (سئو، اعتبارسنجی فرم، خواندن مقالات)
  hooks/          هوک‌های سفارشی (شمارش انیمیشنی، تشخیص کاهش انیمیشن)
content/blog/     مقالات وبلاگ به‌صورت فایل‌های MDX
public/           فایل‌های استاتیک، آیکون‌ها و تصویر پیش‌فرض شبکه‌های اجتماعی
```
