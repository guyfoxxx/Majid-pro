وقتی صحبت از هاستینگ رایگان یا ارزان می‌شود، اغلب فرض بر این است که فریم‌ورک‌های مدرن مثل Next.js به یک سرور Node.js نیاز دارند. اما با قابلیت **Static Export**، می‌توان کل پروژه را به مجموعه‌ای از فایل‌های HTML، CSS و JS تبدیل کرد که روی هر هاست Apache یا Nginx معمولی هم اجرا می‌شود.

## مزیت اول: سرعت بی‌نظیر

فایل‌های استاتیک نیازی به رندر سمت سرور در لحظه درخواست ندارند. این یعنی زمان پاسخ‌دهی سرور تقریباً صفر است.

## مزیت دوم: هزینه نگهداری پایین

بدون نیاز به سرور Node.js، دیتابیس یا مدیریت پروسه، نگهداری پروژه بسیار ساده‌تر می‌شود.

## نکته فنی

در فایل `next.config.js` کافی است مقدار زیر را تنظیم کنید:

```js
output: "export"
```

سپس با اجرای `npm run build`، پوشه `/out` تولید می‌شود که می‌توانید مستقیماً در `htdocs` هاست خود آپلود کنید.
